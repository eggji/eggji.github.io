Does Reinforcement Learning Really Incentivize Reasoning Capacity in LLMs Beyond the Base Model?

Yang Yue, Zhiqi Chen, Rui Lu, Andrew Zhao, Zhaokai Wang, Yang Yue, Shiji Song, Gao Huang
arXiv:2504.13837 · Read 2026-09-28

RL LLM reasoning Post-training Evaluation Empirical study

TL;DR

The paper asks whether RL with verifiable rewards (RLVR) teaches LLMs genuinely new reasoning, or mostly reweights what the base model can already do. Measuring pass@k at large k across model families, RL algorithms, and math, code, and visual reasoning benchmarks, it finds that RLVR raises pass@1 but base models solve more problems at large k, and RLVR's reasoning paths already lie in the base model's distribution. RLVR mainly improves sampling efficiency; distillation from a stronger teacher, by contrast, can expand the reasoning boundary.

Conclusion summary

  • RLVR-trained models beat their base models at small k (e.g. pass@1), but base models reach higher pass@k as k grows. This holds consistently across model families and across math, code generation, and visual reasoning benchmarks.
  • The reasoning boundary narrows with training: as RLVR progresses, pass@1 on the training set improves while coverage (pass@256) decreases. Accuracy histograms show the gains come from sampling more efficiently on problems the base model can already solve, not from solving new ones.
  • Perplexity analysis shows the reasoning paths produced by RLVR models already exist in the base model's output distribution, so the reasoning capacity of current RLVR models is bounded by that of their base model.
  • Six popular RLVR algorithms (PPO, GRPO, Reinforce++, RLOO, ReMax, DAPO) perform similarly. Their sampling efficiency gap relative to the base model's pass@256 stays large (above 40 points) and varies only slightly, so they remain far from optimal. Adding a KL term, using more rollouts per prompt, or raising temperature to match base-model entropy does not close the gap at large k.
  • Distillation behaves differently: a model distilled from a stronger reasoning teacher (DeepSeek-R1-Distill-Qwen-7B) has a pass@k curve consistently above its base model's, so it gains reasoning patterns the base model lacked.
  • The authors conclude that current RLVR has not realized RL's potential to discover novel reasoning, likely because exploration is hard in the vast language space and constrained by the pretrained prior. They point to high-level exploration, curriculum and data scaling, process rewards or fine-grained credit assignment, and multi-turn agentic RL as directions, and note that proprietary frontier models and pipelines limit the study. A preliminary check on Magistral-Medium vs. its base model shows the same trend.
